// my story

How It All Started

I wrote my first line of code at age 14 — a simple Python script that automated my homework spreadsheets. It was clunky, inefficient, and absolutely magical. That moment sparked a curiosity I've never been able to turn off.

When I started university, I quickly realized that textbooks weren't enough. I needed to build real things. So I started side projects — small tools, web apps, CLI utilities — anything that let me apply what I was learning and solve real problems I faced as a student.

My entrepreneurial mindset grew naturally from this habit. I started seeing problems everywhere — in student life, in local communities, in everyday workflows — and asking: "What if I built something to fix this?"

Today, I'm in my third year of Computer Science, actively building projects, contributing to open source, and documenting everything on this blog. My goal isn't just to become a great developer — it's to become a developer who creates meaningful impact.
