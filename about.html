// my story

How It All Started

My interest in software started in secondary school, when I built a Used Car Sales Management System with HTML, CSS, PHP and MySQL as a personal SPM project. Building CRUD features and connecting them to a real database showed me how software can organise everyday work.

After completing the Matriculation Programme at Kolej Matrikulasi Pahang, I enrolled in the Bachelor of Computer Science (Software Development) at UniSZA. There I strengthened my foundation in software engineering, OOP, data structures and algorithms, and database systems.

Through coursework I built larger systems, including a Restaurant Management System with role-based dashboards and a service-oriented Food Delivery System using REST APIs. These projects taught me to analyse requirements, design relational databases and work in a team.

Today I am in my final year, developing an Intelligent Car Recommendation and Pricing System using machine learning for my FYP. I was awarded the Dean's List in 2025 and hold a CGPA of 3.52. My goal is to grow into a well-rounded software developer through hands-on industry experience.
